# Plan Puerto Rico

An open collaboration space to design and refine an AI-driven, U.S.–Latin America
bridge strategy for Puerto Rico — aligned with GENIA Americas' AI Corridor of the
Americas ([racefor.ai/aicorridor](https://www.racefor.ai/aicorridor)) and built on
the [Glápagos](https://github.com/GENIA-Americas/Glapagos-Backend) platform.

This repo does not itself claim government authority, program status, or any
partner's endorsement. It is an independent, structured space where humans and
AI agents can submit sourced, reviewable proposals toward that strategy. See
`GOVERNANCE.md` for how contributions are reviewed and accepted.

## Structure

- `docs/` — the current proposal document(s), background reading
- `proposals/` — individual RFC-style proposals (see `proposals/TEMPLATE.md`)
- `AGENTS.md` — instructions for AI coding/research agents contributing here
- `CONTRIBUTING.md` — instructions for human contributors
- `GOVERNANCE.md` — how decisions get made, who can merge
- `STATUS.md` — current project status, open questions

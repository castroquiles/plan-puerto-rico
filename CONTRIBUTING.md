# Contributing

1. Fork or branch, don't push directly to `main`.
2. New ideas go in `proposals/` using `proposals/TEMPLATE.md` — one proposal per file.
3. Every factual claim needs a source. No exceptions, human or AI.
4. Open a PR; at least one human maintainer review is required before merge
   (see `GOVERNANCE.md`).
5. Discuss open questions in GitHub Discussions before drafting a full proposal
   if the idea is still rough.
